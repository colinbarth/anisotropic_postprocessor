# `anisotropic_postprocessor`

A readable, dependency-light G-code postprocessor and 3D machine simulator for anisotropic 3D printing paths generated by `path_optimizer`.

## Features

- **SI-to-Printer Coordinate Scaling**: `path_optimizer` remains in SI units (`m`). Printer JSON files specify `"coordinate_scale": 1000.0` to convert coordinates into printer millimeters (`mm`).
- **2D, 2.5D, and 3D Modes**:
  - `mode="2d"`: Stack a single 2D layer pattern (`list[Path]`) `n_layers` times.
  - `mode="2.5d"`: Stack distinct 2D layers (`list[list[Path]]`), e.g. multi-angle composite laminates.
  - `mode="3d"`: Emit full 3D coordinated moves from `(n, 3)` paths.
- **PrusaSlicer / Bambu Studio Filament Profiles**: Load filament profiles from JSON (`voxelpla.json`, `generic_cf_pa.json`, or raw PrusaSlicer/Bambu Studio JSON files).
- **Printer Profiles & Programmable Procedures**: Printer JSONs (`raise3d_pro3.json`, `prusa_xl_multi.json`, `generic_reprap.json`) define build volume, temperature/speed limits, and map lifecycle hooks (`start`, `purge`, `layer_change`, `travel`, `retract`, `unretract`, `tool_change`, `cut`, `end`) to plain Python functions.
- **Mid-Path & Inter-Path Procedure Insertion**: Insert any Python procedure at an exact distance along a path (`insert_at_distance(..., from_end=True)` for upstream continuous-fiber cutting), at a vertex index (`insert_at_index`), or between paths (`ProcedureCall`).
- **Siemens NX-Style G-code Machine Simulation**: `parse_gcode` and `plot_gcode` simulate the **actual produced G-code** and render an interactive 3D Plotly toolpath verification view with a chronological step slider, virtual nozzle marker, build plate triad, and event markers.

## Quick Start with `path_optimizer`

```python
import anisotropic_postprocessor as ap

# Load built-in or custom JSON profiles
printer = ap.load_printer("raise3d_pro3")      # or "path/to/my_printer.json"
filament = ap.load_filament("voxelpla")        # or "path/to/voxelpla.json"

# Generate G-code from path_optimizer `final` paths (in meters)
gcode = ap.generate_gcode(
    final,
    printer=printer,
    filament=filament,
    mode="2d",
    n_layers=4,
    z0=0.2,
    layer_height=0.2,
    width=0.4,
    retract=True,
    hop=0.6,
    bed_center=True,
)
ap.write_gcode(gcode, "mbb_fibre.gcode")

# Visualize the produced G-code with interactive machine simulation
fig = ap.plot_gcode(gcode, printer=printer, color_by="feedrate")
fig.show()
```

## Multi-Extruder & Continuous Fiber Cutting

```python
import anisotropic_postprocessor as ap

# Insert a fiber-cut procedure 15 mm before the end of every "fibre" path
paths_with_cuts = ap.add_fiber_cuts(
    final,
    cut_offset_mm=15.0,
    procedure="continuous_fiber_cut",
    kind="fibre",
)

gcode = ap.generate_gcode(
    paths_with_cuts,
    printer="prusa_xl_multi",
    filament={
        "outline": "voxelpla",
        "fibre": "generic_cf_pa",
    },
    tool_map={
        "outline": 0,
        "fibre": 1,
    },
    mode="2d",
    n_layers=4,
    bed_center=True,
)
```
